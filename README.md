# Diplom_3 

# Автотесты UI для Stellar Burgers

Проект с автотестами UI для 
- *Pytest*
- *Seleniumr*
- *Page Object*
- *Allure Report*
- Тесты в окружениях  **Google Chrome** и **Mozilla Firefox**

---

## Протетсированно

### Раздел «Конструктор»
URL: `https://stellarburgers.education-services.ru/`

Проверки:
1. переход по клику на «Конструктор»
2. переход по клику на «Лента заказов»
3. клик по ингредиенту открывает модалку с деталями ингредиента
4. модалка закрывается по клику на крестик
5. при добавлении ингредиента в заказ увеличивается счетчик ингредиента  
   - булки увеличиваются на **2**
   - соусы/начинки увеличиваются на **1**

---

### Раздел «Лента заказов»
URL: `https://stellarburgers.education-services.ru/feed`

Проверки:
1. при создании заказа увеличивается счетчик **«Выполнено за все время»**
2. при создании заказа увеличивается счетчик **«Выполнено за сегодня»**
3. номер заказа появляется в **«В работе»**  

### Запуск тестов

> `pytest -v`

### Запуск тестов с генерацией результатов Allure

> `pytest -v --alluredir=allure-results`
